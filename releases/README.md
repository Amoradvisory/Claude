# Speed Car — APK personnel

Paquet Android de développement signé avec la même clé que la version précédente, permettant une mise à jour sans effacer l’appairage. Aucun jeton de téléphone ni secret propriétaire embarqué. Métadonnées et SHA-256 dans le fichier JSON associé. Les fonctions non testées sur appareil ne sont pas déclarées validées ; voir le rapport 2.0.
